- **[src-query §2] CONNECT BY 의 사이클 검사는 해시가 같은 경로 노드만 값으로 비교한다 — 해시는 "비교가 같으면 같다" 를 지켜야 하는 사전 거름이다** (.52, PR#8474 `4cfc56430`, 2026-11-17): `qexec_connect_by_hash_from_valptr ()`·`_from_tuple ()` 가 열마다 `qexec_connect_by_hash_column ()` 을 접고, 경로 색인(`path_index`)·단일 자식 지름길(`R_hash == child_hash`)이 해시가 같을 때만 `qexec_compare_valptr_with_tuple ()` 을 부른다(query_executor.c 23880~·24600~). PR#8474 는 이 함수가 NULL·컬렉션·JSON 밖의 값을 `qdata_hash_scan_value (dbval, UINT_MAX)` 로 해시하게 해 해시 조인과 같은 ±0·NaN 접기를 쓴다(그 전에는 ±0 만 따로 접어 부호가 다른 NaN 행을 사이클로 못 잡음). 사이클 비교는 출력 목록의 모든 사용자 열이라, 열 하나만 같고 다른 열이 다르면 사이클이 아니다. 머지 전 — PR#8474.
