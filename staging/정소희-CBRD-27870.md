## 머지된 동작 (PR#8364, develop `2dd94e32a`, 2026-11-10 .51 확인 — 정적)
- `pt_buildvalue_output_reads_scan ()`(xasl_generation.c:21460)가 BUILDVALUE 의 출력 목록이 자기 스캔의 값 슬롯을 읽는지 보고, `pt_to_buildvalue_proc ()` 가 `XASL_OUTPUT_READS_SCAN`(xasl.h:605, `0x1 << 30`)을 세운다(xasl_generation.c:21695-21697).
- 그 블록은 페이지 배치를 받지 않는다 — `qexec_batch_eligible ()` query_executor.c:13121-13128.
- 행 루프가 행을 집계할 때마다 `qexec_end_one_iteration ()`(:1322, 호출 :1521)이 `qexec_keep_last_row ()`(:20883)로 스캔 컬럼을 노드의 `last_row`(xasl.h:370-371, 직렬화 안 함)에 복제하고, `qexec_end_buildvalueblock_iterations ()`(:21006, 호출 :21018)가 출력 목록 계산 직전 `qexec_restore_last_row ()`(:20950)로 값 목록에 돌려놓는다. 통과한 행이 없으면 NULL.
- 행 루프 없이 끝나는 블록 — 통계·인덱스 평가, COUNT(*) 의 count-only 인덱스 스캔, 병렬 `gather: buildvalue` — 은 develop·#8196 이전처럼 숨은 컬럼이 NULL (xasl_generation.c:21454-21457 주석). 행 단위 병렬(`gather: row by row`)은 리더가 행마다 집계하므로 복제한다.
- **정정(11-10)**: 이 절의 이전 문장 "`XASL_OUTPUT_READS_SCAN` 블록은 두 빠른 길을 쓰지 않는다(`bfc323a9a`)" 는 리뷰 반영 전 헤드의 동작이다 — 11-09 리뷰(xmilex T5~T7)로 빠른 길을 develop 대로 되돌려 머지됐다(100만 행 MAX ODKU 에서 2.72G instructions 회귀·임의 행 값).
