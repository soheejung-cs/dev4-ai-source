# staging — 환류 대기

아직 `modules/<모듈>.md` §2·§3 에 반영하지 않은 **검증된 코드 사실**을 잠깐 두는 곳.

## 파일 규약
- **파일 하나 = 사람 하나 × 이슈 하나**, 이름은 `이름-이슈명.md` (예: `정소희-CBRD-27369.md`, `송일한-CBRD-27361.md`).
  이슈 키가 없으면 주제를 이슈명 자리에 (`이름-heap-visibility.md`).
- 파일 머리에 `작성: 이름 (컨테이너) · 기준 리비전 · 날짜`. 항목은
  `- **[모듈 §2|§3] 한 줄 주장** (컨테이너, 리비전, 날짜): 근거. 미수정이면 **미수정**.`
- 모듈로 옮길 때 항목 끝에 `— 이름(.컨테이너) YYYY-MM-DD` 서명을 남기고, 다 옮기면 **파일을 삭제**한다(중복 금지).
- 커밋은 **본인 이름으로**(`git config user.name`) — `members/_설정-템플릿.md` 참조. 규약 전체는 `skills/source-learning/SKILL.md`.
